> **"La mejor documentación es la que existe"**

- Documentar mientras desarrollas (no después)
- Incluir ejemplos reales y ejecutables
- Mantener actualizada cuando cambien funcionalidades
- Revisar y archivar documentación obsoleta
- Escribir para desarrolladores futuros
