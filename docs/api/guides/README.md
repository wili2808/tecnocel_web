# 📖 Guías de la API

Guías prácticas y tutoriales para trabajar con la API de TecnoCel Web.

---

## 🎯 Propósito

Esta sección contiene guías paso a paso para:
- Integrar la API en aplicaciones
- Implementar funcionalidades comunes
- Resolver problemas frecuentes
- Mejores prácticas de uso

## 🚀 Inicio Rápido

Para empezar rápidamente, te recomendamos:

1. **Leer** [ENDPOINTS.md](../ENDPOINTS.md) para familiarizarte con la API
2. **Probar** endpoints simples como `GET /marcas` o `GET /productos`
3. **Seguir** la guía de AUTHENTICATION.md para implementar login
4. **Integrar** el carrito siguiendo SHOPPING_CART.md
